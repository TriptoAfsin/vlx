# VLZ menu icons

Monochrome line icons for every menu entry (DESIGN.md › Menus), tinted to the theme's text colour by
`ColorizedSvgIcon` (the `#FF00FF` fill is its placeholder). Registered in `assets.qrc` as `:/menu/vlz-<name>.svg`;
VLC's own icons in `pixmaps/menu/` stay for the dialogs that use them untinted.

Source: [Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons) by Microsoft, MIT licence,
20 px "regular" style, from the `@fluentui/svg-icons` 1.1.292 package. Only the path data is kept.
